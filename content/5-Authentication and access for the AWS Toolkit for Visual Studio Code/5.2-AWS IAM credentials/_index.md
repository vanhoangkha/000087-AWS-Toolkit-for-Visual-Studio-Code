#### Authentication and Connection Using IAM Account

In the **AWS Explorer** section of the user interface, under **Sign in to Get Started**, expand the **Or, provide IAM Roles Credentials** section.

![Amazon Q](/images/00016.png?featherlight=false&width=90pc)

- Enter your **Profile Name**, **Access Key**, and **Secret Key** of your AWS account into the provided fields, then press **Add Profile** to add the profile to your configuration file and connect the Toolkit to your AWS account.

![Amazon Q](/images/00017.png?featherlight=false&width=90pc)

The **AWS Explorer** Toolkit will be updated to display your AWS services and resources after the authentication process is complete and the connection is established.

![Amazon Q](/images/00018.png?featherlight=false&width=90pc)
