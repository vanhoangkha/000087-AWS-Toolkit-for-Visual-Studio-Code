#### Using AWS Toolkit for Visual Studio Code

You don't need to authenticate with AWS to start working with the AWS Toolkit for Visual Studio Code. However, most AWS resources are managed through an AWS account. To access all the services and features of the AWS Toolkit for Visual Studio Code, you need to authenticate with AWS through IAM Identity Center, AWS Builder ID, or IAM credentials.

The following sections provide additional details on each type of authentication information.

- **IAM Identity Center**: This is an AWS authentication management service, allowing you to manage access rights and policies for users in your AWS account.
- **AWS Builder ID**: This is an authentication tool for developers, allowing them to access and manage AWS resources through an easy-to-use interface.
- **IAM credentials**: These are authentication information such as usernames and passwords used to authenticate and access AWS services through APIs or user interfaces.

Proper authentication is extremely important to ensure the security and safety of your account and resources on AWS.
