#### Sử dụng AWS Toolkit for Visual Studio Code

Bạn không cần xác thực với AWS để bắt đầu làm việc với AWS Toolkit for Visual Studio Code. Tuy nhiên, hầu hết các tài nguyên AWS được quản lý thông qua một tài khoản AWS. Để truy cập tất cả các dịch vụ và tính năng của AWS Toolkit for Visual Studio Code, bạn cần xác thực với AWS thông qua IAM Identity Center, AWS Builder ID hoặc IAM credentials.

Các chủ đề sau chứa chi tiết bổ sung về mỗi loại thông tin xác thực.

- **IAM Identity Center**: Đây là một dịch vụ quản lý xác thực của AWS, cho phép bạn quản lý quyền truy cập và chính sách cho người dùng trong tài khoản AWS của bạn.
- **AWS Builder ID**: Đây là một công cụ xác thực dành cho các nhà phát triển, cho phép họ truy cập và quản lý các tài nguyên AWS thông qua giao diện dễ sử dụng.
- **IAM credentials**: Đây là các thông tin xác thực như tên người dùng và mật khẩu được sử dụng để xác thực và truy cập các dịch vụ AWS thông qua API hoặc giao diện người dùng.

Việc xác thực đúng cách là cực kỳ quan trọng để đảm bảo an toàn và bảo mật cho tài khoản và tài nguyên của bạn trên AWS.
