#### AWS Toolkit for Visual Studio Code

AWS Toolkit for Visual Studio Code giúp các dịch vụ và tài nguyên của AWS trở nên dễ dàng truy cập từ giao diện người dùng của VS Code. Dưới đây là danh sách các chủ đề hướng dẫn cho mỗi dịch vụ của Toolkit for VS Code cùng với các tính năng của chúng. Chọn một dịch vụ để biết thêm thông tin về dịch vụ đó làm gì, cách thiết lập nó, và cách làm việc với các tính năng cơ bản của nó.
