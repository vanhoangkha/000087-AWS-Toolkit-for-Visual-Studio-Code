# AWS Toolkit for VS Code: Amazon Q & CodeWhisperer

AWS Toolkit for Visual Studio Code là một tiện ích mở rộng mã nguồn mở, được thiết kế cho trình soạn thảo Visual Studio Code (VS Code). Công cụ này hỗ trợ các nhà phát triển trong việc phát triển, gỡ lỗi và triển khai các ứng dụng không máy chủ bằng cách sử dụng dịch vụ Amazon Web Services (AWS).

#### Amazon Q

Amazon Q là một trợ lý trò chuyện giúp xây dựng, duy trì và biến đổi các ứng dụng. Từ Môi trường Phát triển Tích hợp (IDE), Amazon Q có thể:

- Trả lời câu hỏi về AWS.
- Giải đáp các câu hỏi về các khái niệm lập trình phổ biến.
- Giải thích ý nghĩa của dòng lệnh hoặc các hàm mã.
- Viết các bài kiểm tra đơn vị và mã.
- Gỡ lỗi và sửa chữa mã.
- Tối ưu hóa mã.

#### Amazon CodeWhisperer

Một công cụ tăng cường hiệu suất dựa trên trí tuệ nhân tạo cho các môi trường phát triển tích hợp (IDE).

- Gợi Ý Mã Thời Gian Thực: Tự động gợi ý mã trong hơn 15 ngôn ngữ, bao gồm cả Cơ Sở Hạ Tầng dưới dạng Mã (CloudFormation, AWS CDK và Terraform).
- Tối Ưu Hóa cho Việc Sử Dụng Dịch Vụ AWS: Gợi ý mã được tối ưu hóa cho các API AWS như Amazon Elastic Compute Cloud (Amazon EC2), AWS Lambda và Amazon Simple Storage Service (Amazon S3).
- Quét Bảo Mật Tích hợp: Phát hiện các lỗ hổng bảo mật khó tìm thấy trong mã và cung cấp gợi ý sửa chữa ngay lập tức.
