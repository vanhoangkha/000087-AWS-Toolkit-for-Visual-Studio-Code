#### Thay đổi AWS Region

AWS Region định rõ nơi quản lý các tài nguyên AWS của bạn. AWS Region mặc định của bạn được phát hiện khi bạn kết nối với tài khoản AWS của mình từ AWS Toolkit cho Visual Studio Code, tự động hiển thị trong AWS Explorer.

Các mục sau đây mô tả cách thêm hoặc ẩn một AWS Region từ AWS Explorer.

#### Thêm AWS Region vào AWS Explorer

Hoàn thành quy trình sau để thêm một AWS Region vào AWS Explorer.

Từ VS Code, mở Command Palette bằng cách mở rộng View trên menu chính và chọn Command Palette. Hoặc sử dụng các phím tắt sau:

- Windows và Linux – Nhấn Ctrl+Shift+P.
- macOS – Nhấn Shift+Command+P.

Từ Command Palette, tìm kiếm AWS: Show or Hide Regions và chọn AWS: Show or Hide Regions để hiển thị danh sách các AWS Region có sẵn.

Từ danh sách, chọn các AWS Region mà bạn muốn thêm vào AWS Explorer.

Chọn nút OK để xác nhận các lựa chọn của bạn và cập nhật AWS Explorer.

#### Ẩn AWS Region khỏi AWS Explorer

- Để ẩn một AWS Region khỏi chế độ xem AWS Explorer, hoàn thành quy trình sau.

- Từ AWS Explorer, tìm AWS Region mà bạn muốn ẩn.

- Mở menu ngữ cảnh cho (nhấp chuột phải) AWS Region bạn muốn ẩn.

- Chọn Show or Hide Regions để mở các tùy chọn AWS: Show or Hide Regions trong VS Code.

- Bỏ chọn các AWS Region mà bạn muốn ẩn trong chế độ xem AWS Explorer.
