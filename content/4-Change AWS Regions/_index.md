#### Change AWS Region

The AWS Region defines where your AWS resources are managed. Your default AWS Region is detected when you connect to your AWS account from the AWS Toolkit for Visual Studio Code, automatically displayed in the AWS Explorer.

The following sections describe how to add or hide an AWS Region from the AWS Explorer.

#### Add AWS Region to AWS Explorer

Complete the following procedure to add an AWS Region to the AWS Explorer.

From VS Code, open the Command Palette by expanding View in the main menu and selecting Command Palette. Or use the following shortcuts:

- Windows and Linux – Press Ctrl+Shift+P.
- macOS – Press Shift+Command+P.

From the Command Palette, search for AWS: Show or Hide Regions and select AWS: Show or Hide Regions to display a list of available AWS Regions.

From the list, select the AWS Regions you want to add to the AWS Explorer.

Select the OK button to confirm your selections and update the AWS Explorer.

#### Hide AWS Region from AWS Explorer

- To hide an AWS Region from the AWS Explorer view, complete the following procedure.

- From the AWS Explorer, locate the AWS Region you want to hide.

- Open the context menu (right-click) for the AWS Region you want to hide.

- Select Show or Hide Regions to open the AWS: Show or Hide Regions options in VS Code.

- Uncheck the AWS Regions you want to hide from the AWS Explorer view.
